# Fonts

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling them with
the game. Latin subset, variable weight, downloaded from Google Fonts on 2026-11-27.

- `Cinzel.woff2`: Cinzel by Natanael Gama. Headings, names, prices: Roman inscription capitals.
- `Alegreya.woff2`, `Alegreya-Italic.woff2`: Alegreya by Juan Pablo del Peral (Huerta Tipográfica). Speech bubbles and text.
